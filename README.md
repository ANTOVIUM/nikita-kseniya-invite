# Никита и Ксения — свадебное приглашение

Гостевая ссылка: https://antovium.github.io/nikita-kseniya-invite/

Полное приглашение размещено в корне GitHub Pages без перенаправления. Фотографии, шрифты и музыка загружаются из этого репозитория. RSVP использует существующий защищенный API; ответы автоматически синхронизируются с закрытой Google Таблицей владельца каждые 10 минут. GitHub Pages не запускает серверный код самостоятельно.

Для публикации: Settings → Pages → Deploy from a branch → main → / (root).

Секрет организатора и данные гостей не публикуются в репозитории.
